# 개요
사이트 내에서 후이즈 OpenAPI 을 이용해 도메인 정보를 띄워주는 UI
![예시](https://github.com/gentlecorp/web-deco/blob/main/kisa%20whois/Example.jpg?raw=true)
# 요구사항
* apache2 혹은 nginx
* php
* curl
* WHOIS OpenAPI 키
* 그걸 돌릴 서버
# 주의사항
__KISA OpenAPI 필요__
리눅스의 경우, 권한설정 필수
개발계정의 경우 일일 1만건, 이용 계정의 경우 일일 10만건 초과시 접속차단으로 이용불가.[^1]
